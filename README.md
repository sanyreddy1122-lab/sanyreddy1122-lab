## 🚀 Projects

### 🛡️ RoleGuard – Azure Least-Privilege Role Builder

A web application that converts operational tasks into the minimum required Azure RBAC permissions.

- 🔐 Detects overly broad permissions
- ⚙️ Separates Control Plane and Data Plane access
- 📋 Generates Azure Custom Role JSON
- 🔑 Uses Microsoft Entra ID authentication
- ☁️ Deploys custom roles through Azure Management APIs
- 🚀 Deployed using Azure App Service and GitHub Actions

**Tech:** Next.js • TypeScript • Microsoft Azure • Azure RBAC • Entra ID • REST API • GitHub Actions
